# คู่มือการเชื่อมต่อ Bugfinn Pattern Manager กับ Google Sheet

ระบบนี้รองรับการเก็บข้อมูล Pattern ทั้งหมดลงใน **Google Sheet** ของคุณโดยตรง เพื่อให้ทุกคนในทีมสามารถใช้งานข้อมูลร่วมกันได้แบบ Real-time และสามารถดูหรือแก้ไขข้อมูลผ่าน Google Sheet ได้โดยตรง

---

## ขั้นตอนการติดตั้ง (ใช้เวลาเพียง 2-3 นาที)

### 1. สร้าง Google Sheet
1. เข้าไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างตารางใหม่
2. ตั้งชื่อตารางตามต้องการ เช่น **"Bugfinn Patterns Database"**

### 2. ติดตั้งโค้ด Apps Script
1. ที่เมนูด้านบนของ Google Sheet ให้คลิก **"ส่วนขยาย" (Extensions)** > **"Apps Script"**
2. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs`
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script.js` (หรือกดปุ่มคัดลอกในหน้าเว็บ) แล้ววางลงไป
4. กดปุ่มบันทึก 💾 (ไอคอนแผ่นดิสก์ หรือกด `Ctrl + S`)

### 3. Deploy ให้เป็น Web App
1. คลิกปุ่มสีน้ำเงิน **"ทำให้ใช้งานได้" (Deploy)** มุมบนขวา > เลือก **"การทำให้ใช้งานได้รายการใหม่" (New deployment)**
2. คลิกไอคอนรูปฟันเฟือง ⚙️ ด้านซ้าย > เลือก **"เว็บแอป" (Web app)**
3. กรอกรายละเอียด:
   - **คำอธิบาย (Description):** `Bugfinn Pattern API`
   - **ทำงานในฐานะ (Execute as):** `ตัวฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **`ทุกคน (Anyone)`** *(สำคัญมาก! ต้องเลือก Anyone เพื่อให้หน้าเว็บส่งข้อมูลเข้าได้)*
4. คลิกปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขอสิทธิ์การเข้าถึง (Authorization):
   - คลิก **"ให้สิทธิ์เข้าถึง" (Review Permissions)**
   - เลือกบัญชี Google ของคุณ
   - หากขึ้น "Google ยังไม่ได้ตรวจสอบยืนยันแอปนี้" ให้คลิก **"ขั้นสูง" (Advanced)** > คลิก **"ไปที่ Bugfinn Pattern API (ไม่ปลอดภัย)"**
   - คลิก **"อนุญาต" (Allow)**
6. เมื่อ Deploy เสร็จ คุณจะได้รับ **"URL เว็บแอป"** (ลงท้ายด้วย `/exec`) ให้คลิก **"คัดลอก" (Copy)**

### 4. นำ URL มาใส่ในหน้าเว็บ Bugfinn Pattern Manager
> **หมายเหตุ:** ปัจจุบันในไฟล์ `index.html` ได้เชื่อมต่อกับ URL เว็บแอปของคุณไว้โดยตรงแล้ว (`https://script.google.com/macros/s/AKfycbxtDl7h6CWp7aMSzbV4sCtmqIZjD4b3JajgSg8o8nN0u8uBScWiJ7ubscBsTlgErn3t6w/exec`) ไม่จำเป็นต้องกรอกซ้ำเมื่อเปิดใช้งาน
> หากมีการสร้าง Deployment ใหม่ในอนาคต สามารถเปลี่ยนได้ดังนี้:
1. เปิดไฟล์ `index.html` บนเบราว์เซอร์
2. คลิกปุ่ม **"📊 ตั้งค่า Google Sheet"** บนแถบเมนูด้านบน
3. นำ URL ใหม่มาวางในช่อง **"URL เว็บแอป (Google Apps Script)"**
4. คลิกปุ่ม **"💾 บันทึก URL"** หรือคลิก **"🔍 ทดสอบเชื่อมต่อ"**
5. (แนะนำ) หากต้องการนำ Pattern ทั้งหมดที่มีอยู่เดิมเข้าสู่ Google Sheet ทันที ให้คลิกปุ่ม **"📤 นำข้อมูลทั้งหมดขึ้น Sheet"**

---

## คุณสมบัติหลังเชื่อมต่อ
- ➕ **เพิ่ม Pattern ใหม่:** ข้อมูลจะถูกบันทึกลง Google Sheet และอัปเดตในเครื่องทันที
- ✏️ **แก้ไข Pattern:** ข้อมูลใน Google Sheet จะถูกแก้ไขตามทันที
- 🗑️ **ลบ Pattern:** ข้อมูลในแถวของ Google Sheet จะถูกลบออกทันที
- 🔄 **กดปุ่ม "ซิงค์ข้อมูล":** จะดึงข้อมูลล่าสุดจาก Google Sheet มาอัปเดตบนหน้าเว็บเสมอ
- 📱 **รองรับการทำงานออฟไลน์:** หากไม่มีอินเทอร์เน็ต ระบบจะยังคงเปิดดูและค้นหา Pattern ที่เคยโหลดไว้ในเครื่องได้ตามปกติ
