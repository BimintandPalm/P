# Bugfinn Pattern Manager (My Melody x Cinnamoroll Edition)

เว็บแอปพลิเคชันคลังข้อความสำเร็จรูปสำหรับงานแอดมิน (Bugfinn Pattern Manager) ตกแต่งด้วยธีม Sanrio My Melody x Cinnamoroll พร้อมระบบซิงค์ Google Sheets แบบ Real-time

## 📁 โครงสร้างไฟล์
```text
├── index.html               # หน้าหลัก Pattern Manager
├── page2.html               # หน้าคำนวณค่างวด
├── patterns.json            # ฐานข้อมูล Pattern สำรอง
├── google-apps-script.js    # โค้ด Apps Script สำหรับเชื่อมต่อ Google Sheets
├── GOOGLE_SHEETS_SETUP.md   # คู่มือการติดตั้ง Google Sheets
└── assets/                  # โฟลเดอร์เก็บรูปภาพประกอบทั้งหมด (12 ภาพ)
    ├── banner.png
    ├── nav_heads.png
    ├── search_ribbon.png
    ├── add_melody.png
    ├── cat_ribbon.png
    ├── melody_top.png
    ├── melody_bottom.png
    ├── cinnamon_top.png
    ├── cinnamon_bottom.png
    ├── duo_top.png
    ├── duo_bottom_left.png
    └── duo_bottom_right.png
```

## 🚀 วิธีเปิดใช้งานบน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดขึ้น Repository
2. ไปที่ **Settings** > **Pages**
3. ที่หัวข้อ **Branch** เลือก `main` หรือ `master` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. ใช้งานผ่าน URL ของ GitHub Pages ได้ทันที
